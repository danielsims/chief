# @chief/docs

The public Chief documentation site, served at `docs.heychief.sh`. It is a
standalone Next.js (App Router) app that renders the relay API reference from
the OpenAPI document generated by `@chief/relay-contracts`.

## Run

```sh
pnpm --filter @chief/docs dev
```

## Regenerate the relay OpenAPI reference

```sh
pnpm --filter @chief/docs generate:relay-api
```

This writes `generated/relay-openapi.json` from
`createRelayOpenApiDocument("https://relay.heychief.sh")`. The output is
committed; `predev`, `pretypecheck` and `prebuild` regenerate it automatically.

## Deploy

Vercel project with root directory `apps/docs`, domain `docs.heychief.sh`.
