# PostHog

Use the PostHog MCP tools when the user asks about product behavior, funnels,
retention, feature flags, experiments, session recordings, insights, or errors.

Before mutating projects, flags, experiments, or dashboards, explain the exact
change and preserve Chief's normal confirmation and permission flow. Never ask
the user to paste a PostHog token into chat; Chief owns OAuth credentials.
