# Chief UI

Shared interface components, typography, design tokens, and global styles used by the desktop and web apps.

## Use a component

```tsx
import { Button } from "@chief/ui/components/button";

import "@chief/ui/globals.css";
```

Components use React 19, Tailwind CSS, Radix primitives, Geist, and Newsreader.

## Check types

```bash
pnpm --filter @chief/ui typecheck
```
