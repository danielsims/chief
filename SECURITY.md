# Security policy

## Report a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting for this repository. If that is
not available, email [hello@heychief.sh](mailto:hello@heychief.sh).

Include the affected version, expected impact, reproduction steps, and any
suggested remediation. Remove credentials and personal data from reports. If a
secret has been exposed, revoke it before sending the report.

We will acknowledge reports as soon as practical and coordinate remediation and
disclosure with the reporter.

## Supported versions

Chief is in early preview. Security fixes are applied to the latest release and
the current `main` branch.
